# LinkedIn URL Checker (Vercel)

আপনার ডেস্কটপ প্রোগ্রামের ওয়েব সংস্করণ। ফ্রন্টএন্ড `public/` এ, Python API `api/check.py` এ।

## Vercel-এ চালু করার ধাপ

1. এই ফোল্ডারটি একটি **Private** GitHub রিপোজিটরিতে আপলোড করুন (Public রাখবেন না)।
2. vercel.com এ লগইন করে **Add New → Project** থেকে ওই রিপোজিটরি ইমপোর্ট করুন। Framework Preset হিসেবে **Other** রাখুন, কিছু বদলাতে হবে না।
3. Deploy করার আগে **Environment Variables** এ যোগ করুন:
   - Name: `APP_PASSWORD`
   - Value: একটি লম্বা, কঠিন পাসওয়ার্ড (কমপক্ষে ১৬ অক্ষর)
4. **Deploy** চাপুন। কিছুক্ষণ পর `https://আপনার-প্রজেক্ট.vercel.app` ঠিকানায় সাইট খুলবে।
5. সাইট খুললে পাসওয়ার্ড চাইবে। `APP_PASSWORD` এর মানটি দিন।

## নিজের ডোমেইন যুক্ত করা (ঐচ্ছিক)

1. Vercel প্রজেক্টের **Settings → Domains** এ `checker.zhoujiashan.cn` যোগ করুন।
2. Cloudflare → DNS → Records এ একটি **CNAME** রেকর্ড বানান:
   - Name: `checker`
   - Target: Vercel যে মান দেখায় (সাধারণত `cname.vercel-dns.com`)
   - Proxy status: **DNS only** (ধূসর মেঘ)
3. MX ও ইমেইল রেকর্ডে হাত দেবেন না।

## ব্যবহার

1. **Set cookie** চেপে কুকি দিন, তারপর **Test cookie** দিয়ে যাচাই করুন।
2. URL পেস্ট করুন বা `.txt` ফাইল লোড করুন।
3. **Start test** চাপুন। ফলাফল ফিল্টার, সার্চ, CSV এক্সপোর্ট ও Apps Script জেনারেটর আগের মতোই আছে।

## জেনে রাখা দরকার

- **সংরক্ষণ:** পাসওয়ার্ড, কুকি, URL তালিকা, ডিলে/রিট্রাই ও আগের ফলাফল ওই ব্রাউজারে সংরক্ষিত থাকে, তাই পরের বার খুললে আবার দিতে হয় না। কুকি প্রতিটি চেকের সময় আপনার নিজের Vercel সার্ভারে যায়, সার্ভারে সংরক্ষিত হয় না।
- **নিরাপত্তা:** অন্যের সাথে শেয়ার করা কম্পিউটারে এটা ব্যবহার করলে কাজ শেষে উপরের **Forget saved data** বাটন চাপুন। এতে সব সংরক্ষিত তথ্য মুছে যাবে।
- **LinkedIn ব্লক:** Vercel-এর সার্ভার ডেটা সেন্টারে থাকে। LinkedIn এই IP থেকে আসা অনুরোধ বেশি সন্দেহ করে, তাই `999` এরর, authwall বা কুকি বাতিল হওয়ার ঝুঁকি বাসার কম্পিউটারের চেয়ে বেশি। ডিলে ২-৫ সেকেন্ড রাখুন।
- **সময়সীমা:** প্রতিটি URL আলাদা রিকোয়েস্টে যায়, তাই বড় তালিকাও চলবে। তবে চেক চলাকালীন ব্রাউজার ট্যাব খোলা রাখতে হবে।
- Vercel-এর ফ্রি (Hobby) প্ল্যানের ব্যবহারের নিয়ম ও সীমা সময়ের সাথে বদলায়। ডেপ্লয়ের আগে তাদের বর্তমান শর্ত দেখে নিন।
- LinkedIn স্বয়ংক্রিয় স্ক্র্যাপিং তাদের নিয়মে নিষিদ্ধ করে। এতে আপনার অ্যাকাউন্ট সীমাবদ্ধ বা বন্ধ হতে পারে।
